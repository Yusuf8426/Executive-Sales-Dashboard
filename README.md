# Executive Sales Dashboard – Power BI
## Project Overview
This project is an interactive Executive Sales Dashboard developed using Microsoft Power BI. It provides insights into sales performance, revenue, profit, product categories, and country-wise sales.
## Key Performance Indicators (KPIs)
- Total Revenue: 645.22K
- Total Gross Profit: 296.38K
- Gross Margin: 45.94%
- Total Quantity: 6,698
- Total Orders: 2,707
  ---
## Dashboard Features
- Month-wise Revenue and Profit Analysis
- Top 5 Countries by Revenue
- Bottom 5 Countries by Revenue
- Sales Channel Revenue Comparison
- Product Category Revenue Analysis
- Interactive filters for Quarter, Month, Product Category, and Country
